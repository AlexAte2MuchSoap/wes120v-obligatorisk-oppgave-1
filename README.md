# Mitt WES120V-prosjekt yayyyy

Dette er et minimalt Vite-prosjekt opprettet som en del av WES120V[cite: 1].

## Forutsetninger
- Node.js
- pnpm

## Installasjon og Oppstart
1. Installer avhengigheter: `pnpm install`
2. Start utviklingsserveren: `pnpm dev`
3. Åpne adressen som vises i terminalen (f.eks. http://localhost:5173).
